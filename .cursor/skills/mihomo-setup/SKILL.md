# Mihomo setup (binary + urls.txt)

## Inputs the user provides

1. **Mihomo executable** (any `mihomo*` binary for the OS/arch)
2. **`urls.txt`** — one subscription URL per line (blank lines and `#` comments ignored)

Everything else is generated by this skill.

## Target layout

```
<workdir>/
├── mihomo*                 # user-provided binary (chmod +x)
├── urls.txt                # user-provided subscription URLs
├── mihomo.sh               # control script (from this skill)
└── config/
    └── config.yaml         # generated from urls.txt
```

Default ports: mixed `7890`, socks `7891`, API `127.0.0.1:9090`.

## Agent workflow

Copy this checklist and complete in order:

```
Task Progress:
- [ ] 1. Locate binary + urls.txt
- [ ] 2. Run bootstrap (or generate config manually)
- [ ] 3. Validate config (`./mihomo.sh test`)
- [ ] 4. Start (`./mihomo.sh start`)
- [ ] 5. Bench nodes; select a working one
- [ ] 6. Verify with curl via 127.0.0.1:7890
- [ ] 7. Tell user how to set proxy env vars
```

### 1. Locate inputs

In the workdir (or path the user names):

- Binary: first executable matching `mihomo*` (not `mihomo.sh`). If missing, tell the user to download from https://wiki.metacubex.one/en/startup/ (do not invent or vendor a binary).
- URLs: `urls.txt`

If either is missing, ask the user — do not invent subscription URLs.

### 2. Bootstrap (+ optional shell helpers)

Prefer the project one-shot (from workdir that contains binary + `urls.txt` + this skill):

```bash
./setup.sh
```

Or step by step:

```bash
bash .cursor/skills/mihomo-setup/scripts/bootstrap.sh /path/to/workdir
bash .cursor/skills/mihomo-setup/scripts/install-shell.sh /path/to/workdir --both
```

Bootstrap will:

- chmod +x the binary
- generate `config/config.yaml` from `urls.txt` (one `proxy-providers` entry per URL)
- install `mihomo.sh` into the workdir

`install-shell.sh` adds an idempotent block to `~/.bashrc` / `~/.zshrc` with `mihomo`, `proxy-on`, `proxy-off`. Tell the user to `source` their rc file afterward.

If bootstrap cannot run, generate the same files using [templates/config.yaml.tmpl](templates/config.yaml.tmpl) and [scripts/mihomo.sh](scripts/mihomo.sh). See [reference.md](reference.md) for provider/group rules. User-facing docs: repo [README.md](../../../README.md).

### 3–4. Validate and start

```bash
cd /path/to/workdir
# after install-shell + source:
mihomo test && mihomo start && mihomo status
# or:
./mihomo.sh test && ./mihomo.sh start && ./mihomo.sh status
```

### 5. Pick a working node

**Do not assume the first node works.** Dead upstreams show up as curl `SSL ... unexpected eof` or connection refused.

```bash
./mihomo.sh bench              # rank PROXY members by latency
./mihomo.sh select PROXY 'AUTO'   # or a specific node name from bench
./mihomo.sh now
```

Exact node names from `nodes` / `bench` must be quoted.

### 6. Smoke test

```bash
curl -x http://127.0.0.1:7890 -I --max-time 20 https://www.google.com
```

Expect HTTP 200. If it fails, re-bench and select another node; check `./mihomo.sh log`.

### 7. Client usage (mixed-port, no TUN)

Prefer shell helpers after `install-shell.sh`:

```bash
proxy-on
curl -I https://www.google.com
proxy-off
```

Or export manually:

```bash
export http_proxy=http://127.0.0.1:7890
export https_proxy=http://127.0.0.1:7890
export all_proxy=socks5://127.0.0.1:7891
export no_proxy=localhost,127.0.0.1,::1
```

Browsers usually ignore these; use system proxy or a browser extension.

## Hard rules

- Prefer **proxy-providers** from each URL — do **not** use a full ACL4SSR/Clash dump as `config.yaml` (GeoIP/MMDB downloads often fail).
- Fetch providers with **`proxy: DIRECT`** so subscription updates are not routed through a broken PROXY.
- Avoid GeoIP/GEOSITE-dependent rules in the minimal config unless geodata is already present.
- Never commit real subscription URLs/secrets; keep them in local `urls.txt` only.
- After setup, if SSL EOF / connection errors appear, the local proxy is up but the **selected upstream is dead** — bench and switch.

## Control script cheatsheet

| Command | Purpose |
|---------|---------|
| `./mihomo.sh start\|stop\|restart\|status` | Daemon lifecycle |
| `./mihomo.sh test` | Config validation |
| `./mihomo.sh bench [GROUP]` | Latency table |
| `./mihomo.sh nodes [GROUP]` | List members (`*` = current) |
| `./mihomo.sh select GROUP NODE` | Switch selection |
| `./mihomo.sh now [GROUP]` | Show selection chain |
| `./mihomo.sh log` | Tail `config/mihomo.log` |
